# 🏠 Yerevan Rent Bot

Telegram բոտ, որը օգնում է գտնել վարձով բնակարան Երևանում։ Օգտատերը կարգավորում է ֆիլտրը, իսկ բոտը ուղարկում է միայն համապատասխան նոր հայտարարությունները՝ տանտերերից և գործընկեր ալիքներից։

*Telegram bot for finding rental apartments in Yerevan: users set a filter and get only matching new listings. Armenian, Russian and English.*

## Ինչ է անում

- **Ֆիլտր** — գին (դոլար կամ դրամ), սենյակներ, Երևանի 12 թաղամասեր, կենդանիներ
- **Տանտերերը տեղադրում են անմիջապես բոտում** — քայլ առ քայլ՝ թաղամաս, սենյակներ, գին, նկարագրություն, լուսանկար, համար
- **Գործընկեր ալիքներ** — բոտը ադմին դարձրու ալիքում, և նա ինքը կկարդա նոր գրառումները, կհասկանա գինը, սենյակները, թաղամասը ու կուղարկի համապատասխան օգտատերերին՝ ալիքի հղումով
- **Բողոքներ և սև ցուցակ** — յուրաքանչյուր հայտարարության տակ «Միջնորդ է» և «Խաբեություն» կոճակներ։ 3 տարբեր օգտատիրոջ բողոքից հետո համարը սև ցուցակ է ընկնում
- **Կրկնությունների զտում** — նույն հայտարարությունը 7 օրվա ընթացքում երկրորդ անգամ չի ուղարկվում
- **3 լեզու** — հայերեն, ռուսերեն, անգլերեն
- **Ադմին հրամաններ** — `/stats`, `/ban 091123456`, `/unban 091123456`, `/del 123`

## Արագ մեկնարկ

1. [@BotFather](https://t.me/BotFather)-ում ստեղծիր բոտ (`/newbot`) և պատճենիր token-ը
2. Կլոնավորիր և տեղադրիր.
   ```bash
   git clone <repo-url> && cd yerevan-rent-bot
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env   # լրացրու BOT_TOKEN և ADMIN_IDS
   python -m rentbot
   ```
3. Բաց Telegram-ում բոտը և գրիր `/start`

Python 3.10+ է պետք։ Բազան SQLite է, առանձին սերվեր պետք չէ։

### Docker-ով

```bash
cp .env.example .env   # լրացրու token-ը
docker compose up -d --build
```

## Ալիքների միացում

1. Ավելացրու բոտը ալիքում որպես **ադմին** (բավական է միայն գրառումներ կարդալու իրավունքը)
2. Ցանկության դեպքում `.env`-ում `ALLOWED_CHANNELS`-ում գրիր թույլատրված ալիքների id-ները

Բոտը բաց է թողնում «փնտրում եմ / сниму» և վաճառքի գրառումները, ինչպես նաև այն գրառումները, որոնցում չկա գին և թաղամաս կամ սենյակների քանակ։

> Խորհուրդ՝ ալիքների սեփականատերերի հետ համագործակցիր։ Նրանք բոտը ադմին են դնում, դու նրանց ալիքի հղումը ցույց ես տալիս յուրաքանչյուր հայտարարության մեջ, և երկուսդ էլ օգտատերեր եք շահում։ Կայքերից (օրինակ List.am) ավտոմատ տվյալներ հավաքելը կարող է խախտել նրանց կանոնները։

## Կարգավորումներ (`.env`)

| Փոփոխական | Նշանակություն | Լռելյայն |
|---|---|---|
| `BOT_TOKEN` | Token-ը @BotFather-ից | — |
| `ADMIN_IDS` | Ադմինների Telegram id-ներ, ստորակետով | — |
| `DB_PATH` | SQLite ֆայլի ճանապարհ | `data/bot.db` |
| `AMD_PER_USD` | Փոխարժեք՝ դրամ/դոլար համեմատելու համար | `390` |
| `REPORT_LIMIT` | Բողոքներ մինչև սև ցուցակ | `3` |
| `DAILY_POST_LIMIT` | Մեկ օգտատիրոջ հայտարարություններ 24 ժամում | `5` |
| `ALLOWED_CHANNELS` | Միայն այս ալիքներից կարդալ | դատարկ = բոլորից |

## Կառուցվածք

```
rentbot/
  __main__.py      մեկնարկ, Dispatcher, հրամաններ
  config.py        .env կարգավորումներ
  db.py            SQLite (users, filters, listings, reports, blacklist)
  parser.py        գնի, սենյակների, թաղամասի, համարի ճանաչում տեքստից
  matching.py      հայտարարությունը համապատասխանո՞ւմ է ֆիլտրին
  services.py      ուղարկում համապատասխան օգտատերերին
  texts.py         բոլոր տեքստերը 3 լեզվով
  keyboards.py     կոճակներ
  render.py        հայտարարության և ֆիլտրի քարտեր
  handlers/        start, filters, post, own, report, channel, admin
tests/             parser, matching, database
```
